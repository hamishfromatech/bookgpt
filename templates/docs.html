Getting Started

Initial Setup

  • • Configure your AI provider (OpenAI API key or local LLM like Ollama/LM Studio)
  • • Have your book title, genre, and target word count ready
  • • Choose a writing style: Narrative, Descriptive, Conversational, or Formal

Creating Your First Project

  1. Click "New Project" on the dashboard
  2. Fill in required details: Title, Genre, Target Words (recommended 30K-60K for novels), Writing Style
  3. Add a brief description of your book's premise
  4. Click Create Manuscript

Understanding the Writing Pipeline

BookGPT uses a sophisticated 5-phase agentic pipeline modeled after professional coding agents:

Planning Research Writing Editing Refining

Each phase builds upon the previous one, ensuring narrative coherence and quality throughout your manuscript.

Phase 1: Planning & Outline Generation

The agent creates a detailed chapter-by-chapter outline including story premise, characters, plot points, and character arcs.

💡 Tips for Success

  • • Be specific with genre: The more specific, the better the agent understands reader expectations
  • • Set realistic target lengths: Short stories (5K-10K), Novellas (20K-30K), Standard novels (50K-80K)
  • • Review the outline carefully: You can ask the agent to adjust via Agent Chat before proceeding

Phase 2: Research & Background

The agent gathers background information for world-building, character research, setting descriptions, and genre-specific elements.

💡 Tips for Success

  • • Provide context in description: Include specific world-building elements you want explored
  • • Review research notes: The agent generates research_notes.md with valuable context

Phase 3: Chapter Writing

The agent writes chapters sequentially, maintaining narrative flow, character consistency, and vivid descriptions.

💡 Tips for Success

  • • Let the agent work sequentially: It reads previous chapters to maintain continuity
  • • Monitor progress: Use the monitoring dashboard to track current chapter and total words
  • • Adaptive recovery: If generation fails, the agent automatically tries fallback strategies

Phase 4: Editing & Refinement

The agent performs targeted edits across all chapters for grammar, consistency, pacing, and dialogue quality.

Cross-Chapter Consistency Checks

Before editing each chapter, the agent uses grep_search to verify character name consistency, check location mentions, and flag potential plot holes.

💡 Tips for Success

  • • Review editing notes: The agent generates editing_notes.md summarizing all changes
  • • Use agent suggestions: Proactive recommendations appear in the chat drawer during editing

Agent Chat & Proactive Suggestions

Click "Agent Chat" on the monitoring dashboard to open the sliding chat drawer with your Supervisor AI.

Proactive Suggestion Types

Suggestion When It Appears Action
Review and Edit Chapters 3+ chapters written, not in editing phase Recommends starting editing phase
Check Character Consistency Multiple characters introduced Offers to verify descriptions across chapters
Review Cross-Chapter Consistency During editing with consistency notes Highlights specific inconsistencies found
Export Your Book In refining/completed phase Reminds of available export formats

💡 How to Use Agent Chat Effectively

  • • Be specific: Instead of "make it better", say "expand chapter 3's opening scene with sensory details"
  • • Reference specific chapters: "In chapter 5, the protagonist's motivation feels unclear. Can you clarify?"
  • • Use tool-specific commands: "Check character consistency for 'Sarah' across all chapters"

Exporting Your Book

Once your book reaches the "refining" or "completed" phase, export in multiple formats:

PDF

Proper formatting, chapter headings, page breaks. Best for printing and sharing.

EPUB

Responsive layout, navigation. Best for e-readers and Kindle.

DOCX

Editable format, familiar interface. Best for further editing in Word.

Plain Text

No formatting, universal compatibility. Best for lightweight sharing.

Pro Tips & Tricks

Optimize Writing Style Selection

  • • Narrative: Traditional storytelling with clear plot progression
  • • Descriptive: World-building heavy fiction or literary fiction
  • • Conversational: Contemporary fiction, romance, light reading
  • • Formal: Historical fiction, academic non-fiction, serious literature

Leverage Agent Activity Logging

The activity log shows phase transitions, chapter completion status, tool calls made by the agent, and consistency check results. Use this to understand the agent's decision-making process.

Handle Interruptions Gracefully

If the writing process is interrupted, the agent saves state to the database automatically. Use the "Resume" button to continue from where it left off. Running summaries and activity logs are preserved.

Troubleshooting Common Issues

Chapter Generation Fails or Times Out

Solution: The agent uses adaptive retry strategies with reduced tokens and simplified prompts. If all retries fail, check your LLM provider's API status or rate limits.

Inconsistent Character Names Across Chapters

Solution: Open Agent Chat and use the suggestion "Check character and location consistency across all chapters". Review grep_search results and request targeted edits.

Chapter Seems Rushed or Incomplete

Solution: Check the running summary to verify story progression. Use Agent Chat to request expansion: "Expand chapter X's climax scene with more detail". The agent can use write_file for complete rewrites.
