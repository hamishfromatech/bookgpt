# Screenplay Writer Skill

## Overview

This skill provides specialized guidance for screenwriting and script writing, including:
- Standard screenplay formatting (scene headings, action lines, dialogue)
- Visual storytelling over exposition
- Character introductions and stage directions
- Pacing for visual medium
- Industry standard structure (3-act, 4-act, etc.)
- Dialogue that sounds natural when spoken

## When to Use

Use this skill when:
- Writing film or television scripts
- Creating stage plays or theatrical works
- Developing script treatments or outlines
- Formatting dialogue and action lines properly
- Working within industry standard screenplay formats

## Screenplay Formatting Best Practices

### 1. Scene Heading (Slugline) Format
```
INT. COFFEE SHOP - DAY
EXT. PARK - NIGHT
```
- ALL CAPS
- INT. or EXT.
- Location
- Time of day (DAY, NIGHT, DAWN, DUSK, etc.)

### 2. Action Lines
- Describe only what can be seen and heard
- Use present tense
- Keep paragraphs short (1-3 lines)
- Capitalize character names on first introduction
- Include important visual or audio elements

### 3. Character Introduction Format
```
JOHN (30s), sharp but weary, enters the room.
```

### 4. Dialogue Format
```
        JOHN
        I don't think we should go there.

        JOHN (CONT'D)
        But we have to try.
```
- Character name centered and ALL CAPS
- Dialogue indented
- Parentheticals for action within dialogue: `(looking around)`

## Screenplay Structure

### 3-Act Structure (Feature Film - 90-120 pages)
- **Act 1 (Pages 1-30):** Setup, inciting incident, plot point 1
- **Act 2 (Pages 30-90):** Rising action, midpoint, all is lost moment
- **Act 3 (Pages 90-120):** Climax, resolution

### TV Pilot Structure (50 pages)
- Teaser/cold open
- Act 1: Setup and inciting incident
- Act 2: Complications and mid-point
- Act 3: Cliffhanger or act break preparation

## Visual Storytelling Tips

- "Show, don't tell" - use action to convey emotion
- Avoid internal monologue unless using voiceover appropriately
- Use visual metaphors and symbols
- Let silence and pauses speak as loudly as dialogue

- "Rewrite this scene to show the character's anxiety through action rather than dialogue"
- "Format this script section according to standard screenplay format"
- "Add a visual metaphor to represent the protagonist's isolation"
- "Ensure all scene headings follow INT./EXT. location - time format"

## Validation Checklist for Screenplay Scenes

- [ ] Scene headings follow proper slugline format
- [ ] Action lines describe only what can be seen/heard
- [ ] Character names capitalized on first introduction
- [ ] Dialogue properly formatted with character name and indentation
- [ ] Parentheticals used sparingly and only when necessary
- [ ] Pacing appropriate for visual medium
- [ ] Scene advances plot or develops character
